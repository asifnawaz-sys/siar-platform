BUILD STANDALONE APPLICATIONS
═════════════════════════════════════════════════════════════════════════════

These steps create portable .exe (Windows) and .app (macOS) that run without
requiring Python to be installed.

STEP 1: Install build tools (one time only)
  pip install pyinstaller pywebview wheel

STEP 2: Build for Windows (on Windows PC):
  pyinstaller siar_windows.spec --distpath=dist_windows
  Result: SIAR Digital Platform.exe (in dist_windows/ folder)

STEP 3: Build for macOS (on Mac):
  pyinstaller siar_macos.spec --distpath=dist_macos
  Result: SIAR Digital Platform.app (in dist_macos/ folder)

STEP 4: Test the built application:
  Windows: Double-click SIAR Digital Platform.exe
  macOS: Double-click SIAR Digital Platform.app

STEP 5: Distribute to employees:
  • Copy the entire dist_windows/ folder to Windows users
  • Copy the entire dist_macos/ folder to Mac users
  • They double-click the .exe or .app and start working
  • No Python installation required on their machines

AUTOMATED BUILD (Using GitHub)
═════════════════════════════════════════════════════════════════════════════

For automatic builds on both platforms:

1. Push this folder to GitHub:
   git init
   git add .
   git commit -m "SIAR Platform ready for build"
   git remote add origin https://github.com/YOUR-USERNAME/siar-platform
   git push -u origin main

2. GitHub Actions automatically builds both:
   • Builds Windows .exe on windows-latest
   • Builds macOS .app on macos-latest
   • Creates Release with both downloads

3. Download completed builds from GitHub Releases tab

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

Issue: "python command not found"
Fix: Python not installed or not in PATH. Install from python.org

Issue: "launcher_pywebview not found" when running
Fix: Make sure you're in the correct folder
  cd E:\asif\Downloads\SIAR_Platform_Final

Issue: "Port 5000 already in use"
Fix: Another application using port 5000. Restart computer or change port.

Issue: Application won't start
Fix: Check requirements.txt and run:
  pip install -r requirements.txt
